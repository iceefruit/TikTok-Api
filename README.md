# Plexity TikTok API

Public, best-effort TikTok profile and video metadata API. Returns direct video/audio/thumbnail URLs when TikTok exposes them.

Endpoints: `GET /api/v1/health`, `/api/v1/profile?username=...`, `/api/v1/media?url=...`, `/api/v1/docs`, and `/api/v1/openapi.json`.

npm test
npx vercel dev
